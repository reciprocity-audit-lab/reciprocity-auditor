# Evaluation records

This directory contains a minimal, traceable subset of the Phase 3–3.3 evaluation records. The records are copied without changing the protocols, reported results, comparison labels, or human-review decision.

## Included files

- [`PHASE-3-PILOT-RESULTS-JA.md`](PHASE-3-PILOT-RESULTS-JA.md): Phase 3 pilot scope, deterministic checks, observed strengths, and weaknesses.
- [`PHASE-3-PILOT-IMPROVEMENT-CANDIDATES-JA.md`](PHASE-3-PILOT-IMPROVEMENT-CANDIDATES-JA.md): improvement candidates recorded after the pilot; they are not retroactive changes.
- [`AGGREGATED-METRICS.json`](AGGREGATED-METRICS.json): Phase 3.2 deterministic aggregate metrics.
- [`CASE-MATRIX.csv`](CASE-MATRIX.csv): 9 cases × 3 perspectives, totaling 27 evaluation units.
- [`PHASE-3.2-RESULTS-JA.md`](PHASE-3.2-RESULTS-JA.md): Phase 3.2 summary.
- [`PHASE-3.2-LIMITATIONS-JA.md`](PHASE-3.2-LIMITATIONS-JA.md): Phase 3.2 limitations.
- [`PHASE-3.3-CROSS-PERSPECTIVE-REVIEW-JA.md`](PHASE-3.3-CROSS-PERSPECTIVE-REVIEW-JA.md): cross-perspective comparison summary.
- [`CASE-COMPARISON.csv`](CASE-COMPARISON.csv): 11 axes × 9 cases, totaling 99 comparison units.
- [`DISAGREEMENTS.json`](DISAGREEMENTS.json): traceable comparison observations.
- [`HUMAN-REVIEW-DECISION-JA.md`](HUMAN-REVIEW-DECISION-JA.md): human-review release gate for six high-priority cases.

## Interpretation

Phase 3.2 reports 27/27 PASS across Justice, Reversal, and Tower. This is not a claim of 100% general performance. Phase 3.3 labels comparison relationships, not correctness or fairness scores. It was not an independent human evaluation.

Configuration metadata is incomplete: `model_display_name: null`, `reasoning_setting: null`, and `configuration_comparability: not_demonstrated`. Do not describe the runs as using identical model/reasoning settings or as an independent heterogeneous-model evaluation.
