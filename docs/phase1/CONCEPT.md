# Reciprocity Auditor — 設計思想

## 1. 目的

Reciprocity Auditorは、複数主体に適用される契約やルールを、相互性と手続の観点から構造化する。結論を代行するのではなく、非対称性、自己例外、見落とされた主体、利益相反、救済手続の不足、判断に必要な証拠の欠落を報告する。

## 2. 基礎原則

### 第0原則: 共通契約

複数主体に適用されるルールは、それらの主体が参加可能な共通契約として説明できなければならない。「参加可能」は、必ず全員が作成者であることではなく、適用対象、同意方法、退出条件、変更方法、異議申立てが確認できることを含む。

### 原則1: 契約主体の対等性

各主体を、ルールの目的のための単なる手段ではなく、理由の提示を受け、質問し、異議を述べ得る主体として扱う。対等性は権限・専門性・責任が常に同一であることを意味しない。

### 原則2: 権利と責任の相互性

権利には、それを実現する他者の義務、権利者自身の条件・責任、濫用時の扱いが伴う。権利だけ、または責任だけを一方へ割り当てていないかを確認する。

### 原則3: 契約の公平性・可逆性

提案者や運営者の自己例外、一方だけの取消権、説明不能な免責を抽出する。立場交換テストでは、主体名を交換したときも同じ根拠が成立するかを調べる。ただし能力、費用、受託責任、安全上の役割などに合理的差がある場合は、その根拠と比例性を評価対象にする。

## 3. 区別しなければならない概念

### 契約の相互性

権利・責任・負担・救済が主体間で対応し、例外を共通の理由で説明できるかという構造上の問い。Reciprocity Auditorの中心的な検査対象である。

### 結果の平等

全員が同じ利益、報酬、結果を受け取ること。相互性と同一ではない。貢献量、損失、能力、必要性が異なれば結果が異なる契約もあり得る。Auditorは結果差そのものを違反とせず、差を生む基準、証拠、手続を調べる。

### 手続の公平性

ルールの通知、理由提示、証拠へのアクセス、同じ基準の適用、独立した監督、異議申立て、修正可能性に関する問い。主要な検査対象だが、特定の手続が常に十分だとは断定しない。

### 法的適法性

法域、契約類型、強行法規、判例、事実関係に依存する専門判断。Auditorは法的論点の可能性や専門家確認の必要性を示せるが、適法・違法を確定しない。本出力は法的助言ではない。

### 道徳的正しさ

文化、宗教、倫理理論、共同体の価値に関わる判断。Auditorは価値前提と対立を可視化するが、唯一の道徳的正解を宣言しない。

### 多数派の支持

投票や賛同の多さ。多数決は意思決定手続の一つだが、少数者への負担、利益相反、投票資格、情報格差、基本的保護の不足を自動的に解消しない。逆に少数派であることだけで主張が正しいとも判定しない。

## 4. 監査対象と非対象

主な監査対象:

- 主体、影響主体、権利、責任、負担、危険の対応。
- 例外、免責、裁量、変更権、取消権。
- 判断基準、証拠、執行、監督、利益相反。
- 通知、同意、退出、異議申立て、救済、修正履歴。
- 不足情報、複数の合理的解釈、確信度。

非対象:

- 法的・政治的・道徳的な最終結論。
- 当事者の意図、人格、善意の断定。
- 事実調査を行わずに真偽を決定すること。
- 報告だけを根拠にした自動採択、拒否、制裁、契約執行。

## 5. 合理的な非対称性

非対称性は問題の手掛かりであり、結論ではない。例えば、未成年者保護、緊急停止、機密情報へのアクセス制限、危険作業の資格要件、実費に応じた負担差には合理的根拠があり得る。

合理性を検討する質問:

1. 正当化しようとする目的は明示されているか。
2. 主体間に関連する事実上の差があるか。
3. 手段は目的に適合し、必要以上に広くないか。
4. 期間、範囲、監督、記録、異議申立てがあるか。
5. より負担の少ない代替手段が検討されたか。

Auditorはこれらを質問として提示し、目的の正当性や比例性の最終判断を人間へ残す。

## 6. 説明責任

すべての問題候補には、対象箇所、関係主体、構造上の理由、反対方向の解釈、不足情報、確信度を付ける。点数だけで公平・不公平を宣言しない。`cannot_assess` は失敗ではなく、判断に必要な情報がないことを誠実に示す結果である。
